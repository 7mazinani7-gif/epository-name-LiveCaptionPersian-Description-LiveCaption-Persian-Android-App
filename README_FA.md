# LiveCaption Persian — نسخه ۰٫۹٫۴

اپ اندرویدی زیرنویس زنده با رابط فارسی، دریافت صدای داخلیِ برنامه‌های سازگار، دریافت صدای میکروفون و نمایش زیرنویس شناور روی برنامه‌های دیگر.

## قابلیت‌های پیاده‌سازی‌شده در سورس
- پنجره شناور قابل جابه‌جایی با پس‌زمینه کاملاً شفاف و بدون پنل سیاه.
- نمایش متن اصلی، ترجمه یا هر دو به‌صورت هم‌زمان.
- تنظیم اندازه متن، رنگ متن، رنگ و ضخامت دورخط و سایه.
- راست‌به‌چپ برای متن فارسی و عربی؛ استفاده از آیکون برنامه در سربرگ رابط.
- کلیدهای جداگانه روشن/خاموش برای دریافت صدای داخلی، میکروفون و پنجره شناور.
- دریافت صدای داخلی از طریق Android Playback Capture و تبدیل محلی با Vosk.
- مدل ورودی قابل انتخاب برای فارسی، انگلیسی و عربی؛ مدل هر زبان در اولین اجرا دانلود می‌شود.
- تشخیص زبان متن و ترجمه روی دستگاه با ML Kit Translate پس از دریافت مدل ترجمه.
- نام سازنده در صفحه اصلی: **Mazinani7 & AI**.

## محدودیت‌ها و نکات مهم
- Android فقط صدای برنامه‌هایی را می‌دهد که Playback Capture را مجاز کرده باشند؛ محتوای DRM، تماس‌ها و بعضی برنامه‌ها قابل دریافت نیستند.
- دانلود اولیه مدل‌های Vosk و مدل‌های ترجمه ML Kit به اینترنت نیاز دارد. پس از دانلود، تشخیص Vosk و ترجمه ML Kit به‌صورت محلی انجام می‌شوند.
- تشخیص میکروفون از `SpeechRecognizer` سیستم اندروید استفاده می‌کند؛ پشتیبانی زبان و نیاز به اینترنت به سرویس گفتار نصب‌شده روی گوشی بستگی دارد.
- مدل عربی Vosk بزرگ است و ممکن است روی گوشی‌های دارای فضای ذخیره‌سازی یا RAM محدود کند باشد.
- تنظیمات ظاهری در این نسخه در زمان اجرای برنامه اعمال می‌شوند؛ ذخیره دائمی همه تنظیمات پس از بستن برنامه هنوز اضافه نشده است.
- سورس و ساختار ZIP بررسی شده‌اند، اما APK در این محیط ساخته نشده و هنوز آزمون عملی روی Samsung Galaxy A30 / Android 11 انجام نشده است. بنابراین این نسخه را نباید تا زمان Build موفق و آزمایش روی گوشی، نسخه نهایی تأییدشده دانست.

## ساخت APK با GitHub Actions
فایل `.github/workflows/build-apk.yml` با push به شاخه `main` یا اجرای دستی `workflow_dispatch`، دستور `gradle assembleDebug` را اجرا و APK را به‌عنوان Artifact بارگذاری می‌کند. مسیر خروجی: `app/build/outputs/apk/debug/app-debug.apk`.

## مجوزها و کتابخانه‌ها
- Vosk Android `0.3.75` برای تشخیص گفتار آفلاین.
- ML Kit Language Identification `17.0.6`.
- ML Kit Translate `17.0.3`.
- مجوزهای RECORD_AUDIO، INTERNET، SYSTEM_ALERT_WINDOW و foreground service برای MediaProjection.

**توجه:** سورس اصلاح‌شده به معنی APK ساخته‌شده یا تست‌شده نیست. برای تأیید نهایی باید GitHub Actions با موفقیت اجرا شود، APK نصب شود و دریافت صدای داخلی و پنجره شناور روی گوشی واقعی آزمایش شوند.


## روش جایگزینی در GitHub

این ZIP را ابتدا در گوشی/رایانه استخراج کنید. سپس **محتویات داخل ZIP** را با حفظ ساختار پوشه‌ها در ریشه شاخه `main` مخزن بارگذاری کنید و فایل‌های هم‌مسیر قدیمی را جایگزین کنید. خود فایل ZIP را به‌تنهایی در مخزن آپلود نکنید. پس از Commit، در GitHub Actions باید مرحله بررسی سورس، عبارت `versionName = "0.9.4"` را پیدا کند و Artifact با نام `LiveCaptionPersian-v0.9.4-debug-apk` ساخته شود.
