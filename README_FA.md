# LiveCaption Persian — نسخه ۰٫۴ (نمونه قابل توسعه اندروید)

این فایل، **سورس پروژه اندروید** است؛ APK کامپایل‌شده نیست.

## آنچه در سورس فعلی پیاده‌سازی شده
- رابط فارسی با انتخاب زبان مقصد
- انتخاب سه حالت نمایش: فقط متن اصلی، فقط ترجمه، متن اصلی + ترجمه
- درخواست مجوز نمایش روی برنامه‌های دیگر (Overlay)
- سرویس پنجره شناور قابل جابه‌جایی که پس از خروج از اپ اصلی می‌تواند روی برنامه‌های دیگر باقی بماند
- درخواست مجوز Android MediaProjection برای دریافت صدای داخلی برنامه‌های سازگار
- نمونه تشخیص گفتار از میکروفون با سرویس تشخیص گفتار نصب‌شده روی دستگاه

## محدودیت‌های مهم و صادقانه
- **موتور Whisper یا Sherpa-ONNX هنوز به پروژه متصل نشده است.**
- صدای داخلی که گرفته می‌شود هنوز به موتور تبدیل گفتار به متن وصل نیست.
- تشخیص خودکار همه زبان‌ها و ترجمه واقعی هنوز پیاده‌سازی نشده‌اند.
- پنجره شناور فعلاً متن نمونه/متن تشخیص‌شده از میکروفون را نشان می‌دهد؛ هنوز زیرنویس زنده کامل برای صدای داخلی نیست.
- تشخیص گفتار اندروید از میکروفون ممکن است به سرویس Google یا سرویس گفتار سازنده و اینترنت وابسته باشد و تضمین رایگان/آفلاین بودن ندارد.
- Android Audio Playback Capture فقط صدای برنامه‌هایی را می‌گیرد که ضبط پخش را مجاز کرده باشند؛ تماس‌ها و محتوای محافظت‌شده ممکن است قابل دریافت نباشند.
- سازگاری و پایداری روی Samsung Galaxy A30 / Android 11 هنوز روی دستگاه واقعی آزمایش نشده است.

## ساخت APK در Android Studio
1. Android Studio را روی رایانه نصب کنید.
2. پوشه `LiveCaptionPersian` را از حالت ZIP خارج کنید.
3. از Android Studio گزینه **Open** را بزنید و همین پوشه را انتخاب کنید.
4. در تنظیمات Gradle، از Gradle 8.9 و JDK 17 استفاده کنید؛ Android SDK Platform 35 و Build Tools موردنیاز را نصب کنید.
5. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیرید.
6. APK آزمایشی معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

پیکربندی فعلی: Android Gradle Plugin 8.7.3، Kotlin 2.0.21، **Gradle 8.9**، JDK 17، compileSdk 35، minSdk 29، targetSdk 30.

### نکته سازگاری ویندوز
Android Studio نصب‌شده روی Windows 8.1 ممکن است پشتیبانی نشود. اگر محیط فعلی Sync نشد، از Android Studio سازگار با Windows 8.1 استفاده کن یا پروژه را روی Windows 10/11 باز کن. برای این پروژه Gradle 8.9 لازم است؛ Gradle 9.x را انتخاب نکن.

## مجوزهای موردنیاز
- میکروفون (برای حالت میکروفون)
- نمایش روی برنامه‌های دیگر (برای پنجره شناور)
- اجازه ضبط صدای داخلی از پنجره سیستمی MediaProjection

## گام‌های توسعه بعدی
1. اتصال موتور آفلاین ASR مانند whisper.cpp یا Sherpa-ONNX به PCM صدای داخلی و میکروفون.
2. افزودن مدل‌های زبانی و تشخیص زبان ورودی.
3. اتصال موتور ترجمه آفلاین چندزبانه و نگاشت خروجی به سه حالت نمایش.
4. افزودن مدیریت توقف/ادامه و بازیابی خطا در سرویس پس‌زمینه.
5. ساخت و آزمایش APK روی A30 واقعی، اندازه‌گیری RAM/باتری/تأخیر و انتخاب مدل مناسب.

**هیچ API پولی یا کلید API در این سورس قرار داده نشده است.**
